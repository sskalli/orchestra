# Orchestra product spec

Orchestra is a local workspace for working with multiple Codex tasks. Group related repos in a workspace. Start independent sessions from the map and use the inbox to find the tasks that need your attention.

## Workspace

The left dock shows task activity and opens the source conversation. The right dock shows the selected chat. Preserve drafts by task and keep the viewed area anchored as the docks resize or collapse.

Top-level tasks have large nodes. Native children appear on successive rings as smaller nodes. Use role color when the provider identifies a role, and keep node size tied to hierarchy. Hovering or selecting nodes reveals relevant links. Animate supported parent-child interactions on the map.

## Task sessions

A session can handle a general conversation, a read-only investigation, or work across one or more repositories. Keep planning, user decisions, delivery, and follow-up in the same task chat. The session can delegate through Codex and report results from its children. Child chats are available for inspection.

Explicit implementation approval lets a task edit isolated copies of the selected repositories. Record verification against the exact candidate and show pinned revisions for review. Require the user to merge into project branches separately.

Persist open questions and task history. Make provider failures and interrupted work visible and allow the user to recover without losing the plan or transcript.
